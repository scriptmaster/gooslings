# Exercises

One folder per topic, run in the order listed in `../info.toml`.
Each `.goose` file contains an `// I AM NOT DONE` line; remove it when your
fix is complete. Exercises marked **NOT APPLICABLE** only explain, in their
comments, why the Rust/Zig topic has no Goose counterpart and which Goose
exercise to look at instead; they are skipped by `verify`.

Use `python3 gooslings.py hint NAME` for help and `python3 gooslings.py solution NAME`
to see a reference solution.
